# Security policy

## Reporting a vulnerability

Please don't open a public issue for a security problem. Report it privately through GitHub's [private vulnerability reporting](https://github.com/otherworld-dev/Budget/security/advisories/new) instead, or email adam@otherworld.dev if that doesn't work for you.

Include the Budget and Nextcloud versions, the steps to reproduce, and what you expected to happen. Please use test data rather than real financial records.

You'll get a reply within a week. Fixes ship in a normal release, and the advisory is published once that release is out. Reporters are credited unless they'd rather not be.

## Supported versions

Only the latest release gets security fixes.
